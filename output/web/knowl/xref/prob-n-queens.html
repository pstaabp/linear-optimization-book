Problem 2.1.10. \(n\)-queens problem.

A chessboard is a grid of spaces in which pieces move around the board according to various rules. A queen is a piece that can move left, right, up, down or diagonal any number of squares. Figure 2.1.11 shows the standard 8 by 8 chessboard and one queen.
🔗
The \(n\)-queens problem asks if \(n\) queens can appear on an \(n\) by \(n\) chessboard, so that no queen can attacker another queen.
