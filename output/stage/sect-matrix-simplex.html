    Section 8.3 Performing the Matrix Simplex Method

    We now adapt the simplex method to using the matrices from the previous section instead of a tableau.
    🔗
    Let’s return to Problem 8.1.1, which was written in matrix form in Section 8.1. We use all of the matrix notation from that section to adapt the simplex method to solve such LOPs.
    🔗
    1. Initially the basis for this problem is \(\beta=\{4,5,6,7\}\) and \(\pi=\{1,2,3\}.\text{,}\) therefore the first step is to find \(B\) for this basis which are the 4th throw 7th columns of the simplex tableau or just the identity matrix. Therefore \(B=I\) and also \(B'=I\) and the basic solution is \(B'\boldsymbol{b}\text{,}\) which is just \(\boldsymbol{b}\text{.}\)
      🔗
      \begin{equation*} B' \boldsymbol{b} = \begin{bmatrix} -85 \\ -70 \\ 250 \\ 180 \end{bmatrix}. \end{equation*}
      🔗
      Also, note that the parameter columns (which are quite important in the simplex method) are in \(B'\Pi\) which in the first step, just \(\Pi\) which is
      🔗
      \begin{equation*} \Pi = \begin{bmatrix} -18 \amp -5 \amp -10 \\ -4 \amp -20 \amp -15 \\ 10 \amp 15 \amp 18 \\ 20 \amp 16 \amp 4 \end{bmatrix}. \end{equation*}
      🔗
      Since the left column (which is \(B'\boldsymbol{b}\)) has negatives in this, we need to use phase I. In this case, we find the most negative in this vector, which occurs in the first row. Note that the first row corresponds to \(x_4\text{,}\) so this is the leaving variable.
      🔗
      To find the entering variable, find the largest negative in the first row of \(\Pi\text{.}\) This occurs in the second row of \(\Pi\text{,}\) which is the second variable in \(\pi\text{,}\) so \(x_2\text{.}\) We thus to a pivot \(2 \mapsto 4\text{.}\)
      🔗
      🔗
    2. There the new basis is \(\beta = \{2,5,6,7\}\) and \(\pi=\{1,3,4\}\text{.}\) This means that
      🔗
      \begin{equation*} B = \begin{bmatrix} -5 \amp 0 \amp 0 \amp 0 \\ -20 \amp 1 \amp 0 \amp 0 \\ 15 \amp 0 \amp 1 \amp 0 \\ 16 \amp 0 \amp 0 \amp 1 \end{bmatrix} \qquad \Pi = \begin{bmatrix} -18 \amp -10 \amp 1 \\ -4 \amp -15 \amp 0 \\ 10 \amp 18 \amp 0 \\ 20 \amp 4 \amp 0 \\ \end{bmatrix} \end{equation*}
      🔗
      We can the calculate the determinant of \(B\) to be \(d_{\beta} = 5\) (take the absolute value) and
      🔗
      \begin{equation*} B' = d_{\beta} B^{-1} = \begin{bmatrix} -1 \amp 0 \amp 0 \amp 0 \\ -20 \amp 5 \amp 0 \amp 0 \\ 15 \amp 0 \amp 5 \amp 0 \\ 16 \amp 0 \amp 0 \amp 5 \\ \end{bmatrix} \end{equation*}
      🔗
      And then calculate
      🔗
      \begin{equation*} B' \boldsymbol{b} = \begin{bmatrix} 85 \\ 1350 \\ -25 \\ -460 \end{bmatrix} \end{equation*}
      🔗
      This shows that the tableau is still infeasible and we continue with phase I. We need to find
      🔗
      \begin{equation*} B'\Pi = \begin{bmatrix} 18 \amp 10 \amp -1 \\ 340 \amp 125 \amp -20 \\ -220 \amp -60 \amp 15 \\ -188 \amp -140 \amp 16 \\ \end{bmatrix} \end{equation*}
      🔗
      The smallest (most negative) number in \(B' \boldsymbol{b}\) is in the last row, so the leaving variable is the corresponding leaving variable is the last basis variable or \(x_7\text{.}\) The entering variable will be the largest negative in the 4th row of \(B'\Pi\text{,}\) which occurs in the 2nd column, so the entering variable is the second parameter or \(x_3\text{.}\) We then perform a pivot \(3 \mapsto 7\text{.}\)
      🔗
      🔗
    3. The new basis will be \(\beta = \{2,3,5,6\}\) and \(\pi=\{1,4,7\}\text{.}\) Therefore the result is
      🔗
      \begin{equation*} B = \begin{bmatrix} -5 \amp -10 \amp 0 \amp 0 \\ -20 \amp -15 \amp 1 \amp 0 \\ 15 \amp 18 \amp 0 \amp 1 \\ 16 \amp 4 \amp 0 \amp 0 \\ \end{bmatrix} \qquad \Pi = \begin{bmatrix} -18 \amp 1 \amp 0 \\ -4 \amp 0 \amp 0 \\ 10 \amp 0 \amp 0 \\ 20 \amp 0 \amp 1 \\ \end{bmatrix} \end{equation*}
      🔗
      The determinant of \(B\) is 140, so this is \(d_{\beta}\) and
      🔗
      \begin{equation*} B' = d_{\beta} B^{-1} = \begin{bmatrix} 4 \amp 0 \amp 0 \amp 10 \\ -16 \amp 0 \amp 0 \amp -5 \\ -160 \amp 140 \amp 0 \amp 125 \\ 228 \amp 0 \amp 140 \amp -60 \\ \end{bmatrix} \end{equation*}
      🔗
      and then
      🔗
      \begin{equation*} B' \boldsymbol{b} = \begin{bmatrix} 1460 \\ 460 \\ 26300 \\ 4820 \end{bmatrix} \end{equation*}
      🔗
      There are no negatives in this vector so phase I is complete and we move to phase II.
      🔗
      🔗
    4. In phase II, using the simplex tableau, we need to examine the objective row. In the matrix formulation, we need the coefficient of the parameters in this row and this corresponnds to \(\boldsymbol{c}_{\beta}^{\intercal}B^{-1}\Pi - \boldsymbol{c}_{\pi}^{\intercal}\) and this is calculated for this basis as
      🔗
      \begin{equation*} \begin{bmatrix} 12544 \amp -1008 \amp 0 \end{bmatrix} \end{equation*}
      🔗
      and since there are negatives in this row, it is not optimal. This also shows that the entering variable is the leftmost negative (only in this case) is the 2nd one, corresponding to the 2nd parameter or \(x_4\text{.}\) To find the leaving variable, we need to examine
      🔗
      \begin{equation*} B' \Pi = \begin{bmatrix} 128 \amp 4 \amp 10 \\ 188 \amp -16 \amp -5 \\ 4820 \amp -160 \amp 125 \\ -3904 \amp 228 \amp -60 \\ \end{bmatrix} \end{equation*}
      🔗
      and create \(\boldsymbol{b}\)-ratios using the 2nd column of \(B' \boldsymbol{b}\)
      🔗
      \begin{equation*} \begin{bmatrix} 1460/4 \\ 460/(-16) \\ 26300/(-160) \\ 4820/(228) \end{bmatrix} \approx \begin{bmatrix} 365 \\ -28.75 \\ -164.375 \\ 21.14 \end{bmatrix} \end{equation*}
      🔗
      The smallest ratio is in the 4th row, which corresponds to the 4th basis element or \(x_6\text{,}\) so this is the leaving vector. Therefore we need to perform the pivot \(4 \mapsto 6\)
      🔗
      🔗
    5. We are still in phase II and after the pivot \(4 \mapsto 6\text{,}\) the basis is now \(\beta = \{2,3,4,5\}\) with \(\pi = \{1,6,7\}\text{.}\) The corresponding matrices are
      🔗
      \begin{equation*} B = \begin{bmatrix} -5 \amp -10 \amp 1 \amp 0 \\ -20 \amp -15 \amp 0 \amp 1 \\ 15 \amp 18 \amp 0 \amp 0 \\ 16 \amp 4 \amp 0 \amp 0 \\ \end{bmatrix} \qquad \Pi = \begin{bmatrix} -18 \amp 0 \amp 0 \\ -4 \amp 0 \amp 0 \\ 10 \amp 1 \amp 0 \\ 20 \amp 0 \amp 1 \\ \end{bmatrix} \end{equation*}
      🔗
      The determinant of \(B\) is \(-228\text{,}\) so \(d_{\beta} = 228\) and
      🔗
      \begin{equation*} B' = d_{\beta} B^{-1} = \begin{bmatrix} 0 \amp 0 \amp -4 \amp 18 \\ 0 \amp 0 \amp 16 \amp -15 \\ 228 \amp 0 \amp 140 \amp -60 \\ 0 \amp 228 \amp 160 \amp 135 \\ \end{bmatrix} \end{equation*}
      🔗
      and then since we are in phase II, examine:
      🔗
      \begin{equation*} \boldsymbol{c}_{\beta}^{\intercal}B^{-1}\Pi - \boldsymbol{c}_{\pi}^{\intercal} = \begin{bmatrix} -7680 \amp 1008 \amp -432 \end{bmatrix} \end{equation*}
      🔗
      which shows that this basic solution is not optimal. We use the leftmost negative, which is the first parameter and corresponds to \(x_1\text{,}\) so this is he entering variable. To decide the leaving, we need to find the \(\boldsymbol{b}\)-ratios using:
      🔗
      \begin{equation*} B' \boldsymbol{b} = \begin{bmatrix} 2240 \\ 1300 \\ 4820 \\ 48340 \end{bmatrix} \end{equation*}
      🔗
      and
      🔗
      \begin{equation*} B'\Pi = \begin{bmatrix} 320 \amp -4 \amp 18 \\ -140 \amp 16 \amp -15 \\ -3904 \amp 140 \amp -60 \\ 3388 \amp 160 \amp 135 \\ \end{bmatrix} \end{equation*}
      🔗
      and the \(\boldsymbol{b}\)-ratios are found by dividing elements in \(B' \boldsymbol{b}\) by the elements in the first column of \(B'\Pi\) to get
      🔗
      \begin{equation*} \begin{bmatrix} 2240/320 \\ 1300/(-140) \\ 4820/(-3904) \\ 48340/3388 \end{bmatrix} \approx \begin{bmatrix} 7 \\ -9.29 \\ -1.23 \\ 14.27 \end{bmatrix} \end{equation*}
      🔗
      and the smallest nonnegative ratio is in the first row. This corresponds to the first basis element or \(x_2\text{,}\) so we perform the pivot \(1 \mapsto 2\)
      🔗
      🔗
    6. The pivot \(1 \mapsto 2\) results in the basis \(\beta = \{1,3,4,5\}\) with \(\pi=\{2,6,7\}\text{.}\) The corresponding matrices are
      🔗
      \begin{equation*} B = \begin{bmatrix} -18 \amp -10 \amp 1 \amp 0 \\ -4 \amp -15 \amp 0 \amp 1 \\ 10 \amp 18 \amp 0 \amp 0 \\ 20 \amp 4 \amp 0 \amp 0 \\ \end{bmatrix} \qquad \Pi = \begin{bmatrix} -5 \amp 0 \amp 0 \\ -20 \amp 0 \amp 0 \\ 15 \amp 1 \amp 0 \\ 16 \amp 0 \amp 1 \\ \end{bmatrix} \end{equation*}
      🔗
      The determinant of \(B\) is \(-320\text{,}\) so \(d_{\beta}=320\) and
      🔗
      \begin{equation*} B' = \begin{bmatrix} 0 \amp 0 \amp -4 \amp 18 \\ 0 \amp 0 \amp 20 \amp -10 \\ 320 \amp 0 \amp 128 \amp 224 \\ 0 \amp 320 \amp 284 \amp -78 \end{bmatrix} \end{equation*}
      🔗
      and since we are in phase II, we check:
      🔗
      \begin{equation*} \boldsymbol{c}_{\beta}^{\intercal}B^{-1}\Pi - \boldsymbol{c}_{\pi}^{\intercal} = \begin{bmatrix} 7680 \amp 1280 \amp 0 \end{bmatrix} \end{equation*}
      🔗
      and note that there are no negatives in this vector, so this solution is optimal. The basic solution to this is \(B' \boldsymbol{b}\) for the basic variables or
      🔗
      \begin{equation*} B' \boldsymbol{b} = \begin{bmatrix} 2240 \\ 3200 \\ 45120 \\ 34560 \end{bmatrix} \end{equation*}
      🔗
      and in terms of the original variables, the optimal solution is
      🔗
      \begin{equation*} \begin{aligned} x_1 \amp = \frac{2240}{320} = 7 \\ x_2 \amp = 0 \\ x_3 \amp = \frac{3200}{320} = 10 \end{aligned} \end{equation*}
      🔗
      and the objective is found with
      🔗
      \begin{equation*} z = \frac{1}{d_{\beta}} \boldsymbol{c}^{\intercal}_{\beta} B' \boldsymbol{b} = \frac{320000}{320} = 1000 \end{equation*}
      🔗
      🔗
    🔗
