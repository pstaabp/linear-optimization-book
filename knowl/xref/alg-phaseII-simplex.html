Algorithm 3.2.2. Phase II of Simplex Method.

If a tableau is feasible, then the following steps are Phase II of the simplex method:
🔗
  1. If there are no negative numbers in the objective row, the basic solution is optimal. The algorithm should stop.
    🔗
    🔗
  2. If not, choose the leftmost negative number in the objective row. This is the pivot column. The variable \(x_{j}\) that corresponds to the \(j\)th column is called the entering variable since this variable is entering the basis.
    🔗
    🔗
  3. Create the b-ratio or \(b_{i}/a_{i,j}\) for all \(i\) and for \(j\text{,}\) the pivot column.
    🔗
    🔗
  4. Choose \(i\) such that the b-ratio is the smallest nonnegative ratio. Row \(i\) will be the pivot row. The basic variable in the \(i\)th row is called the leaving variable and denote it \(k\text{.}\)
    🔗
    🔗
  5. Perform a matrix pivot about row \(i\text{,}\) column \(j\) or in terms of a tableau pivot \(j \mapsto k\text{.}\)
    🔗
    🔗
  6. Goto step 1.
    🔗
    🔗
